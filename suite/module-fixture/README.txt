小米本地化统一安装套件 1.1

仅支持 Xiaomi 15 Ultra / xuanyuan / EEA OS4.0.0.6.XOAEUXM / Android17 API37，机主用户0。
这是统一管理模块，安装它不会立即替换所有应用。请在 KernelSU 模块列表展开“小米本地化套件”，点“打开”进入 WebUI。

前置环境
先完成对应系统的 Root、OverlayFS MetaModule、Zygisk 与 LSPosed 安装，并重启验证正常。
套件不刷 boot、不提供 Root，也不修改 Root 隐藏模块。LSPosed 仍由用户在管理器启用并核对作用域。

内置组件
商店1.0、负一屏1.4、小爱1.6、电话短信录音1.7、钱包1.0、天气1.1、相册1.1、自然灾害预警1.1。
另含时钟法定节假日兼容1.0 APK、国行日历18.0.1.30和精确国际日历恢复包。
原组件发布ZIP及小米APK保留原样，不重签、不从历史脚本重建。版本与哈希见 webroot/catalog.json。

手机上安装
1. KernelSU安装本ZIP，重启。只添加统一入口，不自动安装子组件。
2. 打开套件WebUI，确认设备与系统正确，勾选需要的组件。
3. 页面自动补选依赖。首次全新系统请先安装商店并重启，随后再装电话组件；缺少商店时批次会在写入前停止。
4. 点击“安装所选”，检查清单后确认。任务串行执行，关闭页面后仍可继续；重新打开能查看日志。
5. 任务完成后按提示重启。需要LSPosed的组件在页面列明作用域，套件不会写LSPosed数据库。
6. 选择默认电话、短信、数字助理，并按本人需要完成协议、权限、账号和模型下载。
选择安装同版本也会重新调用原组件安装器，可用于恢复后的重新启用；未知版本不强行覆盖。

逐项恢复
商店：开启GetApps、隐藏小米商店并停用模块；应用数据和更新包保留。系统不允许普通停用核心商店，因此使用pm hide；重装会pm unhide。已验证并保留商店4.126.10更新。
负一屏：切Google、停用新助理与挂载；启用小爱时先处理依赖。
小爱：先在系统设置切回其他数字助理；已验证并保留8.2.65.4714更新；停用精确匹配的新增应用，保留数据移除兼容APK、撤销挂载。已有权限与数据保留；重装后须重新核对LSPosed两项作用域，恢复时须重启确认。
电话：验证原默认项、还原精确国际黄页/录音监控，关闭本模块录音RRO，停用国行电话短信并保留数据移除兼容组件。不会清短信/通话数据，国行/data/app包仍保留。
相册：停挂载并恢复未被用户后改的挂载配置；不覆盖照片或数据库。应用商店更新仍保留，因此不等于恢复完整国际版程序。已验证相册5.4.2.10-0907-cn、编辑器2.10.40.4.8；未知更新在执行前停止。
天气：调用精确恢复脚本，验证国际天气和核心两者的哈希；保留数据与已有权限。
预警：保留数据移除兼容APK并停用手机管家挂载，重启后回国际程序；不自动覆盖旧设置备份。
日历：保留应用数据切换两版日历，不操作com.android.providers.calendar；未知更新或多用户时阻止。
时钟：先把法定重复闹钟和作息改回普通规则，再在LSPosed停用；套件提供说明和入口，不自动改闹钟。
钱包：没有批量恢复或重置按钮。仅已完成精确CN TSM迁移的手机允许重复安装；首次迁移/恢复须核实当前卡片、共享UID及eSE凭据后单独处理。

状态与失败处理
“已启用”表示模块标记启用；“已安装”表示APK匹配；均不代表全部端到端功能已验证。
“待生效”需先重启，禁止继续覆盖同一组件。套件检查空间、来源哈希、当前版本和必要依赖。
一个任务失败后停止后续组件，日志记录已完成步骤。任务不是跨应用的原子事务，不能假定失败等于完全未改动。
任务被重启或进程退出中断后显示“已中断”，不会开机自动重放。应检查已完成步骤再决定恢复或重装。
任务中不可通过套件重启；系统外部重启仍可能中断任务。私人任务记录保存在/data/adb/xuanyuan-os4-suite-state。
卸载套件只移除管理入口和离线安装材料，不自动卸载已经安装的功能模块。请先按需逐项恢复。

复用边界
本版不支持随意放入其他APK、其他机型或其他系统。新系统/应用更新须重新核验并制作相应适配包。
不携带个人数据、协议同意状态、模型缓存、账号、卡片、LSPosed数据库或签名私钥。
不自动开启报警、录音或拨打任何电话。钱包与预警等服务实际可用性仍以各组件实测记录为准。

1.1变更

手机已确认LSPosed2.2.1/API102；现有兼容APK仍使用legacy API，不能以更改版本声明代替迁移。
