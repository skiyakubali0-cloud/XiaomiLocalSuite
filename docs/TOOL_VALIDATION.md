# 桌面工具 0.5.0 验证记录

本记录针对 `tool-v0.5.0` 桌面工具预览版，日期为 2026-10-16。
它不是手机套件 1.7 的新一轮实机验收。

## 本地检查

- macOS：Python 3.13.13、Tk 9.1、Java 17、Android SDK build-tools 36.0.0。
- 多机型工具共运行 135 项测试，其中 2 组需要私有历史材料的集成测试明确跳过。
- 源码打包、启动器、发布扫描及现有重建工具共 45 项测试通过。
- 使用真实 SDK 创建临时自签名测试 APK，通过 GUI 控件的分析、勾选、检查和生成流程，
  核对候选包内 APK 原字节、校验和、构建记录及选择变化后的检查失效行为。
- 检查缺少 SDK、Java 过旧、签名工具不可运行、可选解包器缺失时的环境报告。
- 检查带空格路径、启动器参数边界、旧输出保护、源码文件范围、危险 ZIP 成员拒绝、
  逐文件摘要及相同提交的确定性打包。启动检查不联网、不打开手机连接。
- 打开真实 macOS 窗口核对默认导入入口和底部操作按钮布局；没有上传窗口截图。

## 现有固件材料检查

使用已有的小米 15 Ultra `xuanyuan`、EEA `OS4.0.0.6.XOAEUXM` 和同机型国行解包材料：

| 来源应用 | 结果 |
| --- | --- |
| 通知管理 | 静态通过，生成本地候选 ZIP 并核对全部校验和 |
| 常用语 | 国行版本低于目标版本，阻止生成 |
| 悬浮球 | 新增特权电话状态权限，阻止生成 |
| 日历 | 新增权限，要求单独审阅配方，阻止生成 |

这次通知管理的来源和目标版本均为 41028400，材料相同，只证明导入、选择和打包流程可用，
不证明增加了国行功能。候选 ZIP 留在本地，没有上传到仓库或 Release，也没有安装手机。
本轮没有重新解包完整 OTA；解包流程的空间、失败清理及输入限制由合成材料测试覆盖。

## 发布与未验证范围

源码包从已提交 Git 对象生成；包含软件提交编号和逐文件 SHA256，不包含 Git 历史、
小米 APK、固件、SDK、依赖缓存、个人数据或密钥。Release 附带工具 ZIP 的独立摘要文件。
CI 会重建并验证工具包，Linux 检查结果以标签对应提交的 GitHub Actions 为准。

Windows 原生完整流程未验证；发布包中的 Windows 启动脚本只提供运行入口和提示。
Windows 用户应在具备图形支持的 WSL2 / Linux 环境中准备依赖并运行 Linux 启动器。
WSL2 也未单独做实机验收。

没有在新机型安装候选模块，没有执行恢复出厂、Root 安装、重启、真实通知、电话、
报警、支付或门卡操作。工具环境通过、APK 证书通过和候选生成成功，均不代表这些功能可用。
普通导入不会自动加入统一 API 102 插件、权限修复或完整国行功能迁移；钱包保持单独验证。
