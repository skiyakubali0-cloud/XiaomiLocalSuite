# 公开版本的脱敏边界

此仓库由选定源码和文本模板全新初始化，没有复制原工作目录的Git历史、私人备份或设备数据。

已排除：原厂APK/固件/库/DEX、完整套件ZIP、个人签名密钥、真实密码/令牌、钱包数据与卡片凭据、手机序列号、账号、个人绝对路径、截图、日志、LSPosed数据库、测试观测数据及macOS元数据。

模块作者字段改为项目contributors；Git提交使用公开账户的GitHub noreply身份。Android包名、机型代号、ROM版本、原厂APK/框架SHA256、API签名和运行时`/data/adb`路径为软件协议/校验，不作为个人信息删除。删除这些值会破坏拒绝未知版本的行为。

构建器接受调用者自己的签名配置。签名密码通过环境变量交给工具，不打印到命令或构建报告；开发构建使用的测试密钥不上传。测试中的虚构sentinel、临时夹具密码和`oem.invalid`是测试数据，不能用于生产。

本次发布扫描仅对公开提交集合及新建Git历史负责，不承诺所有未来贡献都无敏感数据。`tools/check_public_tree.py`和CI提供持续检查，不能替代人工审查。私有材料哈希清单用于兼容校验，不含设备/账号/钱包凭据。

本地重新构建及扫描结果见`docs/VALIDATION.md`；构建成功不代表新签名产物已在手机测试。
