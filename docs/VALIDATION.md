# 公开源码验证记录

本记录针对脱敏源代码，而不是原私人签名安装包。

- 原始参考：私有套件1.7，xuanyuan EEA OS4.0.0.6 Android17/API37。公开代码保留原SHA/机型/UID门禁。
- 公开构建使用调用者新签名，不能直接覆盖旧签名手机插件。旧手机安装结论不继承为公开构建的实机结论。
- libxposed API/service/interface 102.0.0从Maven Central实际下载，SHA256与lock一致；没有上传AAR/JAR。
- 公开工具和测试不调用ADB、不连接手机、不注册推送、不发送消息、不执行支付/卡片/报警。
- `suite/multi-device`的两组私有1.4完整材料测试没有随源码分发；未提供该包时明确跳过，不作为已通过实机/材料检查。设置`RUN_SELECTED_SUITE_INTEGRATION=1`要求精确材料，否则失败。
- 隐私/预警主机测试保留生产源文件中的原DEX哈希；只在临时编译的测试class中将其映射到合成字节的哈希，同时验证拒绝错误字节和重试，不分发OEM DEX，不声称校验了真实OEM类布局。
- 公开最终检查：工具21项、多机型130项（其中2组私有材料测试明确跳过）、钱包24项、统一插件86项，全部通过；另通过23项API102派发、18项反射、784项电话/时钟/建议和66588项隐私/预警host断言。
- 使用独立临时签名实际构建APK，通过签名与API compileOnly校验；临时签名key已删除，没有读取或复制旧手机私钥。
- 用公开构建器、公开文本模板、本地精确参考包和上述新签名APK实际生成完整私有套件；校验315个文件摘要、215项锁定材料和11项组件目录配对，Shell语法及经典ZIP检查通过；未安装手机、不发布该含原厂材料的ZIP。
- Git初始提交只包含源码、文本模板、材料哈希和文档；249个文件的公开集合自动扫描与独立只读隐私审查均未发现发布阻塞；不包含私人历史。
