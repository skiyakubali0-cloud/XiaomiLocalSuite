## 实际原始材料与产物

- 从现有 stock 固件材料及原签名 APK 解析 **214/214 项**所需材料；没有读取旧套件或私有参考 ZIP。
- 使用此前提取的真实目标属性及未修改原库；本轮没有重新解包整份 OTA。
- 公开配方成功生成 11 项派生材料，包括智能助理原生补丁、两版天气补丁、预警 DEX 和标记文件，输出均匹配 lock。
- 使用当前公开 Java 源码、固定 API102 依赖、真实 JDK/SDK 及临时测试密钥编译签名统一 APK；构建证据校验通过，测试密钥已删除。
- 成功生成包含全部 11 项组件的本地 1.7 parent ZIP，大小 **1,101,464,844 字节**。
- 核对全部 214 项材料的字节及 SHA256、父包与 8 个子包的校验清单、目录和 payload 摘要；51 份 shell 文件语法通过。
- 实际操作 macOS Tk 控件，完成完整模式的分析、勾选商店/智能助理、检查及生成：部分包 **68,557,262 字节**，只包含所选组件与共享统一插件。
- 生成结果未含钱包重置授权标记，未安装到手机；含 OEM 材料的两个 ZIP 和本地报告未公开。

## 下次复用

按 [完整路线教程](FULL_RECIPE.md) 准备精确目标目录、CN 材料和缺项提示中的额外 APK，
用自己的长期密钥构建当前统一插件，勾选、检查并生成新 ZIP。新签名不能直接升级旧私人签名插件。
用户另行安装 parent 后，在 LSPosed 启用统一插件，在手机组件配置中检查并按计划分批应用。

能力 CSV 仅限制本包组件配置页的选择及安装。省略组件不卸载已有模块、不清除旧偏好，也不自动关闭其他页面的兼容开关或既有 hook；需要停用时单独关闭或恢复。

钱包不随批量全选加入，桌面不创建 reset 标记。若明确打包并在手机选择钱包，首次 EEA→CN TSM 迁移仍须手机独立确认，仅授权该次任务；已有精确 CN TSM 不重复清除。全局 XMSF 保持不变。

本轮没有手机安装、重启、录音、真实推送、报警、支付或卡片操作。生成成功不表示这些业务功能通过新一轮实机验收。
